# ViralForge AI 🚀

### AI-Powered Viral Content Generation Platform

ViralForge AI is a modern full-stack AI SaaS platform built to help creators, marketers, and brands generate high-performing short-form content in seconds.

The platform uses AI-driven workflows to generate:

* Viral hooks
* Reel/TikTok scripts
* Captions
* Hashtags
* Viral score predictions
* AI-powered thumbnail concepts

Designed with a scalable SaaS architecture and a modern creator-focused UI/UX.

# ⚙️ Setup

## Backend

```bash id="h3k8va"
cd BackEnd

python -m venv venv

# Windows
venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```

---

## Frontend

```bash id="g9m2xr"
cd FrontEnd

npm install

npm run dev
```
